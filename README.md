## ✦ About The Project

This project is an interactive Apple-inspired product experience created to explore modern frontend development, 3D visualization and motion design.

Instead of creating a traditional product landing page, I focused on building an immersive interface that combines **3D models, animations, product interactions and video storytelling**.

The goal was to create a premium and responsive browsing experience inspired by modern product websites.

---

## ✨ Features

- 📱 Interactive 3D iPhone model
- 🎨 Product color selection
- 🎬 Interactive product video sections
- ✨ GSAP-powered animations
- 🖱️ Smooth scroll interactions
- 📐 Responsive design
- ⚡ Vite-powered development environment
- 🌐 Real-time 3D rendering
- 🧩 Reusable React components
- 🎥 Integrated product videos

# 🧊 3D Experience

The project uses **Three.js** and **React Three Fiber** to render and control the 3D iPhone model directly inside the browser.

The 3D experience includes:

- Product rotation
- Different product configurations
- Camera positioning
- Lighting
- Smooth transitions
- Interactive product presentation

---

# 🎬 Motion & Animation

GSAP is used throughout the website to create smooth and controlled animations.

Some of the animation work includes:

- Scroll-triggered animations
- Product transitions
- Section reveals
- Video transitions
- Navigation interactions
- 3D model transitions
